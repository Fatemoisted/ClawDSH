## Debugging note: first typecheck failure and fix

- **Symptom**: `pnpm run typecheck` reported `[clawdsh] Cannot find entry: lib/types/{index,invariant,startup}.js` at the tsdown host stage.
- **Root cause**: tsdown's workspace scan is directory-granular (`onlyDirectories: true`), so the `packages/openclaw/*` skeleton directories were swept in; no package.json inside the directory → root resolution walked up to the root package (name=`clawdsh`) → resolving the entry with the root config failed. The earlier "no package.json in the skeleton" strategy only blocked pnpm, not tsdown.
- **Fix**: the root `tsdown.config.ts` workspace was changed to object form with an explicit `exclude: ['packages/openclaw/**']` (exclude wholesale-replaces tsdown's built-in defaults; the four default patterns were kept verbatim). This change was recorded in ADR-0001 decision 4's "build-orchestration minimal exemption".

- **WS-B** (PR #6, this change): memory host watcher + lexical-fallback verdict.
